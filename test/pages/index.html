启动本地服务后，通过 http://127.0.0.1.nip.io:8000/ 访问 （nip.io 将该域名解析到 127.0.0.1，同时让页面域名不是 localhost/纯 IP， 以便扩展的检测逻辑正常工作）：

python -m http.server 8000 --bind 127.0.0.1
