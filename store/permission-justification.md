# 商店权限说明（Permission Justification）

> 提交 Chrome Web Store 与 Edge Add-ons 时，Privacy practices / 权限说明处逐项粘贴。
> 依据：docs/扩展开发最佳实践.md 第三节（上架阻塞项清单）。

## 单一用途说明（Single Purpose）

拦截银狐木马（Winos/ValleyRAT/游蛇）的钓鱼网站与仿冒软件下载站：在导航层对威胁情报黑名单做请求级拦截、对可疑域名做启发式评分告警，并在页面层识别仿冒品牌下载站、对高风险文件下载发出警告。

## host_permissions: `<all_urls>`

扩展的核心功能是"对所有网页导航进行钓鱼风险评估"，无法预先穷举恶意域名列表（银狐钓鱼域名每天批量新增）：

1. **导航级检测**：需要对任意 http/https 主导航的域名做威胁情报黑名单匹配与启发式评分（typosquatting、银狐偏好后缀、模板词）。
2. **页面级检测**：内容脚本需要读取页面标题/正文与下载链接，识别"声称某品牌但非官方域名 + 提供安装包"的仿冒下载站。
3. **下载防护**：需要判定下载来源站点是否可疑，对来自可疑站点的 .exe/.msi/.zip 下载发出警告。

扩展不读取、不存储、不上传任何页面内容——检测仅在本地完成，结果（域名级别）保存在本地。

## 各 API 权限

| 权限 | 用途 |
|---|---|
| `declarativeNetRequest` | 将威胁情报黑名单中的域名在浏览器网络层直接重定向到扩展内置警告页（请求级拦截，恶意页面不加载）。规则来自本地情报名单，仅作用 main_frame 导航 |
| `webRequest` | 观察式（非阻塞）监听主导航请求：启发式评分与"疑似站点"告警层的入口；与 DNR 形成"已确认硬拦 + 疑似告警"两层 |
| `downloads` | 监听下载创建事件：当下载 .exe/.msi/.zip 等高风险文件且来源站点命中黑名单/疑似时弹出警告通知 |
| `notifications` | 展示高风险下载警告通知 |
| `alarms` | 每日定时拉取公开威胁情报 feed 更新本地黑名单；清理过期的"仍要访问"会话放行规则 |
| `storage` | 本地保存用户设置、白名单、拦截统计与情报缓存；不上传任何数据 |
| 内容脚本注入 | 页面级仿冒特征检测（品牌声称 + 非官方域名 + 安装包链接）与警告条注入；`document_idle` 时机注入，降低性能影响 |

注：扩展使用的 `chrome.tabs.update/query/create`（警告页跳转与放行回跳）不需要 `tabs` 权限，manifest 已按最小权限原则裁剪（未声明 `tabs`/`webNavigation`）。

## 远程代码（Remote Code）

**否**。扩展不加载、不执行任何远程托管的代码。每日更新的威胁情报均为**纯数据**（域名/URL 文本列表，来自 LGSRC / OpenPhish / URLhaus 等公开 feed），由扩展内置解析器在本地解析为黑名单。

## 数据使用披露

- 不收集、不传输、不出售任何个人身份信息或浏览数据（详见仓库 PRIVACY.md）
- 唯一对外请求：① 拉取公开威胁情报 feed（每日/手动）；② 对启发式评分已可疑的站点向公共 RDAP 服务查询域名注册年龄（仅发送域名，不发送用户信息；正常网站不触发）
- 所有检测与存储均在本地完成
